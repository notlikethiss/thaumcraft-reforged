# Thaumcraft 3 Reforged

A port of **Thaumcraft 3.0.5e** by Azanor from Minecraft 1.5.2 to **Minecraft 26.3** on **NeoForge 26.3**.

The goal is to recreate the original gameplay as closely as possible: aspects, aura nodes, vis and flux, the crucible, arcane and infusion crafting, research and the Thaumonomicon. Mechanics and numbers are ported 1:1 from the decompiled original. The technical side is rebuilt on modern APIs (data components, attachments, payloads, render states), and JEI integration is planned on top.

> **Personal use only.** Thaumcraft and all of its assets belong to Azanor. This repository contains the original mod's logic and assets and is not intended for redistribution.

## Requirements

- Java 25
- Python 3 (only for the conversion and resource generation scripts)

Versions used by the build:

- Minecraft `26.3`
- NeoForge `26.3.0.40-beta`
- ModDevGradle `2.0.148`
- JEI `31.8.0.53`

## Building and running

```sh
export JAVA_HOME=/path/to/openjdk-25

./gradlew compileJava   # compile
./gradlew build         # build the mod jar into build/libs
./gradlew runClient     # start a development client
./gradlew runServer     # start a development server (game folder: run/)
```

The server's stdin is forwarded, so it can be driven by a file of commands:

```sh
tail -f cmds | ./gradlew runServer
echo "forceload add 0 0" >> cmds
```

## Admin commands

- `/thaumcraft research <players> <key|all>` grants research
- `/thaumcraft note <players> <key> [progress 0..1]` gives a research note

## Tools

Resources are generated by Python scripts instead of datagen:

| Script                        | Purpose                                                                                                                                       |
| ----------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| `tools/convert_assets.py`     | Converts original textures, sounds and `.lang` files (to JSON with new keys) and research XML. Extra strings live in `tools/lang/<lang>.json` |
| `tools/gen_resources.py`      | Generates blockstates, models, loot tables, recipes and tags into `src/generated/resources`                                                   |
| `tools/convert_tags.py`       | Generates `aspect/ConfigAspects.java` from the original `Config.initTags`                                                                     |
| `tools/convert_research.py`   | Generates `research/ConfigResearch.java` from the original research config                                                                    |
| `tools/convert_structures.py` | Converts the mound structure from the original world generator                                                                                |
| `tools/remap_srg.py`          | Remaps SRG names in the decompiled source to MCP names                                                                                        |

The scripts read from `reference/` (git ignored), which holds the original mod decompiled with Vineflower and remapped to MCP 1.5.2 names, plus Minecraft 26.3 and NeoForge sources for reference.

## Localization

English and Russian are supported. The Russian research texts have their own set of pages (`assets/thaumcraft/research/<lang>.xml`).
